# Lizenzen der Bilder unter public/assets/sky/

Himmelskuppel. Zugeordnet sind sie ueber `DEFAULTS` in `sky.mjs`: ein Bild je
Bodenpalette. Ein Planet kann das mit `sky: { image, horizon }` in
`config/colony.config.json` ueberschreiben. Was weder `DEFAULTS` noch ein
Planet nennt, gehoert nicht in diesen Ordner.
